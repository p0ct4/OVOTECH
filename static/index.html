OVOTECH

Incubadora inteligente

OVOTECH es un proyecto que permite controlar y monitorear la temperatura y humedad de una incubadora utilizando un ESP32 y sensores.

Los datos se envían a una página web, donde se pueden consultar en tiempo real desde una computadora o celular.

¿Qué hace OVOTECH?

Temperatura

Permite conocer la temperatura dentro de la incubadora.

Humedad

Muestra el porcentaje de humedad registrado por los sensores.

Monitoreo online

Los datos se pueden consultar desde la página web mediante internet.

Sobre el proyecto

OVOTECH fue desarrollado como un proyecto de informática que combina electrónica y programación.

Utiliza un ESP32 para obtener las mediciones de los sensores y enviarlas a un servidor. Luego, la información se muestra en una interfaz web sencilla para que el usuario pueda consultar el estado de su incubadora.
